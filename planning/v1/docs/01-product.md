# 01｜產品範圍與使用流程

版本：Plan 1.0｜日期：2026-10-04｜狀態：可開始實作的產品基線

## 1. 產品定義

為台灣高中學生提供離線英文詞彙查詢與自動安排的學習。使用者只要指定想學的英文、每日可投入時間，以及可選的考試日期；App 負責補內容、選題、安排新內容與複習、估算考前可完成範圍。

產品目標是改善詞彙在閱讀與考試語境中的使用，不宣稱取代完整英文課程、保證考試成績、或只靠詞彙量即可具備留學與口說能力。大考中心考試說明還包括語法、篇章理解、翻譯與寫作等能力。[S02]

## 2. V1 的交付範圍

| 編號 | 必須交付 |
|---|---|
| R01 | iPhone 優先；自己與同學試用；繁體中文介面與釋義。最低 iOS 版本由實作時依所用 API 決定並記錄，原則是不要求手機升到最新系統。 |
| R02 | 核心查字與學習完全離線、無帳號、無 App 內 LLM API、無自建伺服器、無內建遙測上傳。 |
| R03 | 正式 V1 內容目標為約 10,000–12,000 個英文 headword；另有獨立片語清單。屈折變化、英美拼法別名不拿來灌詞條數。 |
| R04 | Word 和 Phrase 分開呈現、分開記錄進度；都支援搜尋、加入、考試歸屬與長期複習。 |
| R05 | 只輸入英文即可；搜尋、一鍵加入、逐行大量貼上。整行片語不能按空白拆成多個單字。 |
| R06 | 同一項目跨來源、跨考試只維持一份學習狀態；重複加入不重置歷史。 |
| R07 | 課文照片、OCR、文件解析、聊天式生成、卡片編輯器不做。外部 AI 整理出的英文清單可直接貼上。 |
| R08 | 詞庫提供常用/考試重要義項、詞性、繁中解釋、例句、搭配或用法、词形別名、發音資訊；內容品質與來源可追溯。 |
| R09 | 正常啟動：今日尚有適合做的計畫內容時直接學；今日目標完成或暫無適合內容時進字典。字典 Widget 深連結永遠直達字典。 |
| R10 | 不要求 Again/Hard/Good/Easy、自評熟悉度、每日新字數、每日選單字本或題型。 |
| R11 | 題型以點擊式語境、搭配、義項辨識為主，少量短輸入；寫作加強才提高拼字及產出要求。 |
| R12 | 每個已提交回答立即保存；中斷不算錯；回來續接。進度不依賴按「結束學習」。 |
| R13 | 每日一份總時間預算，涵蓋所有考試與一般學習；可零碎累積。 |
| R14 | 考試只改變期限與優先度；考後不刪字、不重置，回到長期學習。 |
| R15 | 查字不自動加入；反覆查詢可提示，一定要明確按加入。已有項目只能安排診斷，不因查詢直接扣熟悉度。 |
| R16 | 未收錄項目顯示本機無資料，提供使用者主動點擊的 Cambridge 外連；不能加入，不能抓取或轉存 Cambridge 內容。 |
| R17 | 資料備份/還原、匯出、刪除、詞庫版本升級、故障復原屬於 V1，不延到同步版本。 |
| R18 | Widget 提供字典和繼續學習入口。通知是選用功能，首次啟動不要求通知權限。 |
| R19 | 完整詞庫前有 200 詞＋30 片語的內部驗證版；這是工程里程碑，不能冒稱已交付一萬詞 V1。 |
| R20 | 個人化先做到實際耗時、負荷調整與記憶排程；「個人吸收極限/疲勞曲線」是後續需驗證的模型，V1 不假裝精確知道。 |

片語第一版內容製作的起始目標為 300 個常用片語；屬工程範圍，不是學術界認定的必要數量。經試用調整清單，但不得以自動拼接搭配詞湊數。

## 3. 不在 V1

Android、Web、桌面原生 App、CloudKit 同步、登入、付費牆、訂閱、班級管理、排行榜、語音辨識、自由作文批改、全文課本匯入、執行時生成題目、完整文法課程。

這些不阻止資料設計保留跨平台能力；也不應使第一版多出未使用的服務框架。

## 4. 首次使用

只有時間預算是必要設定，例如 15 分鐘，可調整。這個示例值不是建議的「最佳學習時間」。

下一步可搜尋/貼上英文；沒有內容時進字典並提供清楚的加入入口，不強迫先設定考試、帳號、程度測驗或教材。若使用者自願選擇內建清單，應一次明確加入，而非偷偷讓整本詞庫都成為待背內容。

每日分鐘數之後可改，當日已花時間照實保存。把預算改小不會刪掉已完成的學習，也不會禁止繼續。

## 5. 主要畫面與導航

底部只需「學習」「字典」兩個主要入口；計畫、進度與設定從工具列進入。左右滑可以作捷徑，但必須有可見的點擊入口，不能只靠手勢。

### 學習

顯示當前一道題、必要的回饋，以及低干擾的今日時間狀態。不要出現未校準的「掌握 97.3%」。沒有強迫 session 長度、倒數答題或結束流程。

作答後可看完整正解、該義項與一句解釋；選項不能只變紅綠而沒有文字。答錯不扣排行榜、不斷 streak、不觸發羞辱式提示。聲音不預設自動播放。

預算耗盡：完成當前題目後回到「今日目標完成」與字典；可明確點「繼續學習」，新增時間另行記錄。不得宣稱所有到期複習已完成，除非確實如此。

### 字典

搜尋結果先精確字，再別名/詞形，再前綴，最後明示「可能是」的拼字建議。顯示詞性、重要義項、例句、搭配與發音；詳細內容可展開。

單字和片語有清楚類別。按加入立即完成並有撤銷入口；不跳出單字本/優先度問卷。一般搜尋預設加入「一般學習」；從某考試內搜尋則加入該考試，畫面要有可見考試標籤。一般查字不默默歸入推測的考試。

字典義項順序保持穩定。可以標記目前正在學的義項，但不依不可靠的個人狀態重排整份詞典。

### 計畫與考試

建立考試只填名稱、日期，選用「需要英文書寫」。來源或批次可以一起歸入考試。每日總時間設在個人設定，不能每個考試各有 20 分鐘而相加成 60 分鐘。

日期預設解讀為「考試當天開始前準備好」，儲存建立時的時區，並顯示預計在前一日完成準備。更細的考試時間可後加，不是 V1 必填。

顯示：原始範圍、目前基礎達標範圍、較完整練習範圍、未確認範圍、預估時間是否足夠。考前縮減深度時不能縮小分母後顯示「全數掌握」。

## 6. 啟動與中斷狀態機

優先順序：
1. 外部明確深連結：字典 Widget → 字典；學習 Widget → 學習或今日完成頁。
2. 使用中從背景回前景：保留正在看的頁面，不強迫跳題。
3. 一般冷啟動：有未完成題目且仍適用 → 原題；否則有今日可做內容 → 下一題；否則字典。

已呈現的選項排列、題目版本、輸入草稿保存；回來不能重新洗牌讓原選項改位置。退出不是答錯。若跨日，仍可完成原題，但作答時間與計畫歸屬以實際發生時間記錄。

原題因更新被撤銷：提示「這題已更新，改做另一題」，不計錯，保留原因事件。

## 7. 批次匯入與超出詞庫

V1 支援貼上逐行清單及 UTF-8 文字檔；CSV 可作後續小項，不需為它先做大型匯入框架。
- trim、Unicode 正規化、大小寫不敏感搜尋。
- 保留整行片語；不得靠空白切詞。
- 精確 lemma 優先；唯一詞形映射可以自動合併。
- saw/axes 這類多解別名不可盲目猜。集中顯示待確認清單，其他項目正常處理。
- 已存在、未收錄、成功解析、需確認各自計數。
- 預覽後一次確認加入；不要求提供中文。

未收錄外連使用固定 HTTPS 主機與 URLComponents 編碼 query。無網路時明示外部查詢需要連線，不把網頁錯誤當本機查字失敗。

## 8. 查詢訊號

只有打開詞條才算 lookup，不把每次鍵盤輸入記成查字。相同項目在短時間連續開啟去重。

建議的起始提示規則：14 天內至少 3 個不同日期查同一項目，且不在學習池，才在詞條底部顯示一鍵加入提示；拒絕後 30 天不再提示。這些是可調產品常數，不是記憶科學結論。

已有項目反覆查詢：建立一次 pending diagnostic，不改動 FSRS 的成功/失敗歷史。診斷放在後續正常學習，避開剛查完答案；不知道查的是哪個意思，就不能宣稱某一義項忘了。

## 9. 無障礙與手機操作

支援 Dynamic Type、VoiceOver、深色模式、Reduced Motion；選項長度不能截斷核心資訊。主要按鈕容易單手點擊，正確/錯誤不用顏色單獨表達。不要求固定幾秒內閱讀完成，也不以讀得慢判定不會。

寫作加強的輸入需關閉會洩漏答案的自動校正/預測設定（在系統容許範圍內），並真機檢查。大小寫永遠不扣詞彙拼字分。

## 10. 本文件之後的改動規則

需求變更需在決策紀錄寫「改了什麼、為什麼、影響哪些驗收」。演算法常數可版本化調整，不能為了 demo 好看改成較寬鬆的作答結果。只在真的涉及目標族群、資料授權/付費承諾或產品功能範圍時再向使用者確認；技術和文獻問題由開發者查證。
