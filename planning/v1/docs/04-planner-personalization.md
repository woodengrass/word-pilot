# 04｜時間預算、考試規劃與個人化：要達成什麼

本文件只寫要求與驗收。可參考的演算法、出題順序與起始數值見 `docs/08`「可參考的做法」；實作可以替換，只要滿足這裡的要求並記錄理由。

## 1. 目標

- **有考試時**：在指定的完整範圍、期限、是否需要書寫與每日時間的限制下，盡量提高考試當天在沒看過的代表性語境題上的表現。
- **沒有考試時**：在同樣的時間內，持續提升長期有用的詞彙能力，不要求所有義項都維持同樣高的記憶率。
- 記憶率、已學字數、證據狀態、積欠量都只是代理指標，不能為了它們製造無止境的複習。
- V1 是可解釋的規劃器，不宣稱已找到每分鐘的最佳得分。

## 2. 每日時間是上限

- 使用者只設一個每日總時間，涵蓋所有考試與一般學習；多場考試不能各自加總時間。
- 時間用完就在當前題目結束後停下；可以自願繼續，額外時間另外記錄，不當成之後每天都有。
- 到期的複習不是必須清償的債：沒做完的保留風險資訊，隔天**重新排優先順序**，不疊加。漏學幾天後回來，不把缺的份量一次塞回，也不偷偷增加每日時間。
- 介面只顯示今天的份量，不顯示「欠了 110 題」。
- 「今日完成」不等於全部到期項目都完成，不能這樣宣稱。
- 時間不足、沒有合格題目或目標已達合理程度時，可以結束今天的安排，不硬湊題填滿時間。

## 3. 目標記憶率是手段，不是目標

- 每個學習目標要維持多高的記憶，由系統依內容價值、考試遠近、時間壓力、個人記憶曲線與已有證據決定；使用者不設定，也不全部固定同一個值。
- 調整要平滑，不能讓排程忽高忽低；每次調整要能說明原因。
- 已有充分跨日、跨語境成功證據的能力，可以用較低成本維持；之後答錯或風險上升就恢復加強。
- 是否比固定值好，以 beta 相同投入時間下的未見題表現驗證。

## 4. 新內容、複習與考試覆蓋要平衡

必須避免：

- **複習被餓死**：持續加新內容，讓到期複習長期輪不到。（模擬中「新內容一律優先」會讓沒有考試時的實際記憶率掉到約 76%。）
- **新內容被餓死**：有考試時固定先清光複習，導致指定範圍內大批內容到考前都沒接觸。
- **新內容造成未來超載**：今天開太多新內容，讓之後幾天的複習超出每日時間。加入 2,000 個字不代表當天就建立全部複習任務。
- **重複作業**：因為每個義項、題型各有狀態，就機械地要求全部做完；或同一題已驗證的能力被立刻重測。
- **刷好看**：同一題反覆刷、只出容易題來提高表面正確率。

另外：

- 同樣的輸入必須得到同樣的結果；每次選題、延後或降低練習強度都要記錄原因。
- 查字後的診斷與跨語境檢查不能擠掉正常學習。
- 正在作答的題目不因背景重算而被換掉。

## 5. 考試

- 考試只填名稱、日期、是否需要英文書寫；日期預設為當天開始前要準備好，保存建立時的時區。
- 進度的分母永遠是**使用者指定的原始範圍**；不能縮小分母後宣稱達標，也不能因為詞頻低就默默剔除使用者指定的字。
- 考前時間不足時：先保住範圍內高價值的義項與用法，延後低價值的深度；不能把核心縮成「看過中文」，也不能把第二義、搭配全部丟掉（它們本身常是考點）。評分標準不因時間不足而放寬。
- 時間仍不夠時，誠實列出尚未接觸、尚未驗證的部分，可以建議增加時間或調整期限，但不強迫。
- 同一個字在多場考試只保留一份學習狀態，作答只算一次；兩場考試互相競爭時依迫近程度與缺口分配，分別顯示各自未覆蓋的部分。
- 一般學習與較晚的考試可以暫時讓位，但不能長期被忽略。
- 考後只移除期限壓力，保留進度與長期複習。

## 6. 預估（forecast）

- 預估以原始指定範圍為分母，呈現考前可能的覆蓋與不足；至少給快、中、慢三種情境，不能只給單一數字（例如「你只要 17.3 分鐘」）。
- 預估必須使用和實際選題相同的規則，不能另用一套樂觀算法。
- 未校準的記憶預測不能顯示成考試分數，也不能稱為有保證的信賴區間。
- 太遠的未來只給粗估。
- 在背景執行、可取消；使用者作答不必等預估完成。

## 7. 計時與個人耗時

- 只計學習畫面上實際活動的時間（題幹、輸入、回饋、短教學都算）；背景、鎖定、字典查閱不計。長時間無操作要標記為不確定，不能拿來判斷疲勞或答錯。
- 牆上時間被修改不能產生負的作答秒數；跨日的時間要切開；學習日的切換時間與規則要版本化，不能回頭改寫已發生的統計。
- 短文多小題共享的閱讀時間只算一次。
- 依題型估計每個學生的實際耗時；資料少時要穩健、不劇烈波動，規劃時偏保守。答得快但一直錯不能被當成高效率；錯誤後的補救時間要算進去。
- 初始耗時只是估計種子，要先用內部試用的實測替換，再對每個人更新。

## 8. 疲勞

不從「越後面越錯」直接推論疲勞（可能是題目較難、環境中斷或時段不同）。V1 不輸出個人「最佳學習上限」，不鎖住使用者，不顯示醫療或心理診斷，也不因「疲勞」改出大量簡單題。

## 9. 模擬驗收門檻

因為不規定規劃器怎麼寫，所以用模擬學生測試驗收。M4 要建立一個可重現的模擬工具（固定 seed）：模擬學生的記憶依 FSRS 遺忘曲線，學生間記憶速度有差異，題目耗時有隨機變化，可設定缺天。排程與個人化必須通過：

| 情境 | 門檻 |
|---|---|
| 任何情境 | 系統排出的份量不超過每日時間（使用者自願加時除外） |
| 無考試、每天 15 分鐘、清單足夠、持續 180 天 | 到期複習時的實際記憶率（模擬中的真實值）後半段平均 ≥ 85% |
| 有考試、範圍大於時間能完成的量 | 考試當天範圍內「已接觸且預測記得」的比例，不低於「先清光到期複習再學新字」的基線 |
| 約每週缺 2 天 | 回來當天份量仍在預算內；後半段實際記憶率 ≥ 80% |
| 個人參數更新 | 每次更新造成的既有排程平均變動 ≤ 10%、最大 ≤ 20%；採用新參數後預測誤差不變差 |
| 同樣輸入跑兩次 | 結果完全相同 |

門檻來自規劃時的模擬（好的排法約 88%，「新內容一律優先」約 76%；有保護的個人化每次變動 3–6%），是工程門檻，beta 後可調。模擬結果只證明排程合理，不證明真人學習有效。`claude/simulations` 分支的 Python 模擬可作參考。

## 10. 衡量標準

比較**相同時間下未見考試型題目的表現、考前原始範圍的覆蓋、長期負荷趨勢**。只把複習任務變少，不能宣稱學習更有效。
